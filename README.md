【一、运行环境要求】
1. Windows 10 / 11，或 Ubuntu / Linux 桌面版（需要图形会话：本机显示器或远程桌面；
   纯命令行服务器需自行配 Xvfb 虚拟显示，未实测）
2. 已安装 Google Chrome 或 Chromium 浏览器（Windows 默认路径即可；Linux 自动从
   PATH 与 /usr/bin 等默认路径查找，装在自定义路径时可设置环境变量 CHROME_PATH）
3. 已安装 Python 3.10 或更高版本（Windows 安装时勾选 Add Python to PATH）
4. 网络环境：本机开启美区（US）代理，或在控制台左侧填写代理模板

【二、快速启动步骤】
Windows：
1. 首次使用请双击运行：【1_首次运行_安装依赖并启动.bat】
2. 之后日常使用直接双击：【2_启动控制台.bat】
3. 浏览器会自动打开控制台页面：http://127.0.0.1:8765
Ubuntu / Linux：
1. 首次使用在终端运行：chmod +x *.sh && ./1_首次运行_安装依赖并启动.sh
2. 之后日常使用运行：./2_启动控制台.sh （或直接 python3 app.py）
3. 浏览器打开控制台页面：http://127.0.0.1:8765

【三、自定义填写支付卡 & 跑号说明】
1. 填写支付卡（必填）：
   - 在网页左侧【全局配置与内联免税绑卡】区域，填入你自己的 Visa 或 Mastercard 外币卡：
     * 卡号（16位数字）
     * 有效期（月 / 年，如 08 / 29）
     * 安全码（3位 CVC）
     * 持卡人英文姓名
     * 免税邮编默认已填好 97201（美国俄勒冈免税州），无需修改
   - 填写后点击【💾 保存配置】。
   - ⚠️ config.json 内含真实卡号/CVC 与账号密码/2FA 密钥，已被 .gitignore 忽略且不再纳入 Git 追踪，**切勿手动提交或分享该文件**；仓库内只保留无敏感信息的 config.example.json 模板。
   - 注：脚本内置严格 0 元消费保护，仅在结账弹窗确认为 US$0.00 时才会点击订阅，全程 0 扣费。

2. 批量导入 Google 账号：
   - 在网页右侧【批量放号导入区】粘贴账号（每行一个），支持以下任意格式：
     * 邮箱----密码----辅助邮箱
     * 邮箱----密码----辅助邮箱----2FA密钥
     * 邮箱----密码----2FA密钥
   - 点击【➕ 一键导入账号列表】。

3. 开始全自动执行：
   - 点击单个账号右侧的【▶ 执行】或顶部的【▶ 批量全自动执行】。
   - 脚本会自动完成：
     Step 1: 自动登录 Google 并通过辅助邮箱 / 2FA 验证
     Step 2: 内联免税绑卡 + 首层 12 个月免费包 (US$0.00)
     Step 3: 叠加二层 6 个月免费包 (US$0.00 -> 18个月)
     Step 4: 叠加三层 6 个月免费包 (US$0.00 -> 24个月封顶)
     Step 5: 自动前往 Google Play 取消自动续订，锁死 2 年到期权益并截图验真

【四、安全加固说明（本 fork）】
1. 零消费保护改为 fail-closed 精确判定：必须命中带货币符号的精确 0.00（如 US$0.00），
   且弹窗任意位置出现非零金额（如 $10.00、次月 $19.99）一律拦截不点击订阅。
2. 日志脱敏：CVC、2FA 动态码、代理账号不再明文打印（统一 [***] / [******]）。
3. 移除以 Win32 原生 API 指定交互桌面会话的穿透式启动（杀软启发式报毒特征），
   改为常规 subprocess 启动 Chrome。
4. 成功判定只认正式回执词；“备用付款方式/以后再说/知道了”等过渡词不再算成功，
   并强制校验 Google Play 订阅页真实到期日（Step2/3/4/5 均验真，不过关不报完成）。
5. 前端账号列表不再明文渲染密码，导入文本渲染前全部转义，防注入。
6. profiles/（含已登录会话 Cookie）、screenshots/ 同样已加入 .gitignore。
注意：若你曾经把填有真实信息的 config.json push 到公开仓库，请立即换卡/改密/重置 2FA——
从 Git 删除文件并不能清除历史提交中的副本。
